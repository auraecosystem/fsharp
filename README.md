# F# Core Libraries & Modules

A collection of functional utility modules, domain abstractions, and tools for the **Aura Ecosystem**, built with [F#](https://fsharp.org/) and the .NET ecosystem.

---

## Overview

This repository provides strongly-typed, functional components designed to integrate seamlessly across the Aura Ecosystem services. It emphasizes immutability, type safety, and functional-first domain modeling.

---

## Features

- **Domain-Driven Design (DDD):** Pure functional domain models leveraging F# discriminated unions and record types.
- **Asynchronous & Concurrent:** Built-in support for `Async`, `Task`, and actor-based concurrency.
- **Cross-Platform:** Targets .NET 8.0+ for cross-platform deployment (Linux, macOS, Windows).
- **Interoperability:** Native integration with existing .NET libraries and C# services.
